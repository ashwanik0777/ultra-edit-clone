UltraEdit for Mac System Requirements

UltraEdit for Mac runs on all macOS systems 11.5 and later, with support for Intel and Apple processors.

UltraEdit for linux System Requirements

UltraEdit is a native Linux application. It does not require WINE or any other translation layer for installation and use and will run on both the GNOME and KDE desktops.
